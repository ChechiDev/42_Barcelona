# Exercise 0: Entering the Matrix

Create `ex0/construct.py` to inspect the current Python environment.

## Requirements

- Detect whether the script runs inside a virtual environment.
- Display the current Python executable.
- Display virtual environment name and path when present.
- Display instructions to create and activate a virtual environment when absent.
- Show package installation path for the active environment.
- Authorized modules: `sys`, `os`, `site`, and `print()`.
- Do not submit a virtual environment.

## Expected concepts

- Difference between global Python and a virtual environment.
- `sys.prefix`, `sys.base_prefix`, executable paths, and site-packages paths.
- Deterministic output structure with dynamic environment values.
