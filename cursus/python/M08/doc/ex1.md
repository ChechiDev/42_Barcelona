# Exercise 1: Loading Programs

Create `ex1/loading.py`, `ex1/requirements.txt`, and `ex1/pyproject.toml` to demonstrate package management and data analysis.

## Requirements

- Use pandas for data manipulation.
- Use numpy for numerical computations and dataset generation.
- Numpy must be the source of the simulated Matrix dataset, not hardcoded lists or `range()`.
- Use matplotlib for visualization.
- Optionally use requests only if fetching external data.
- Detect missing dependencies gracefully.
- Show installed package versions.
- Explain pip and Poetry dependency management through program output.
- Generate a visualization such as `matrix_analysis.png` when dependencies are available.

## Expected concepts

- Dependency checks with helpful install instructions.
- Reproducible simulated data generated by numpy.
- Separation between dependency inspection, data generation, analysis, and visualization.
